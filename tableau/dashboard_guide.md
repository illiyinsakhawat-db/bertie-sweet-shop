# Tableau dashboard – build guide

> The finished workbook is already in this folder: **`bertie_sweets_dashboard.twbx`** (packaged, data included). It is generated by `scripts/build_tableau_workbook.py`, which writes `bertie_sweets_dashboard.twb`. Open the `.twb` in Tableau and use *File → Export Packaged Workbook* to refresh the `.twbx`. If you move the repo, re-run the script so the CSV paths point to the new location. This guide documents what the workbook contains, so you can rebuild or extend it by hand.

The dashboard tracks **product sales performance**, **category revenue trends** and **repeat purchasing behaviour**. Every data source comes from a SQL view in [`sql/03_views.sql`](../sql/03_views.sql), so all business logic lives in the database. Tableau only handles presentation.

## 1. Connect the data

| Option | When to use | How |
|---|---|---|
| **CSV extracts** (in `tableau/data/`) | Tableau Public (free) | *Connect → Text file* → pick the CSVs below |
| **Live PostgreSQL** | Tableau Desktop / Server | *Connect → PostgreSQL* → schema `bertie` → drag in the `vw_*` views |

**Relationships (data model "noodles")**

```
order_line_sales ──(order_id)──► order_summary ──(customer_id)──► customer_summary
monthly_category_revenue      (stand-alone, pre-aggregated)
product_performance           (stand-alone, pre-aggregated)
cohort_retention              (stand-alone, pre-aggregated)
```

Cancelled orders are already excluded in `scripts/export_for_tableau.sql`, so no data source filter is needed.

## 2. Calculated fields

```text
// Net Revenue (product sales, excl. delivery)
SUM([net_revenue])

// Average Order Value
SUM([order_total]) / COUNTD([order_id])

// Repeat Order %
SUM(IIF([new_vs_repeat] = "Repeat", 1, 0)) / COUNT([order_id])

// Repeat Customer Rate  (customers with 2+ orders)
COUNTD(IIF([order_count] >= 2, [customer_id], NULL)) / COUNTD([customer_id])

// Discount Rate
SUM([discount_amount]) / SUM([gross_revenue])

// YoY Growth % (table calculation on a monthly line chart)
(ZN(SUM([net_revenue])) - LOOKUP(ZN(SUM([net_revenue])), -12)) / ABS(LOOKUP(ZN(SUM([net_revenue])), -12))
```

## 3. Sheets

| # | Sheet | Source | Chart | Rows / Columns / Marks |
|---|---|---|---|---|
| 1 | **KPI tiles** | order_summary | Text | Revenue, Orders, AOV, Repeat Order % (one sheet per tile, or Measure Names) |
| 2 | **Revenue trend by category** | monthly_category_revenue | Stacked area | Columns `MONTH(order_month)` · Rows `SUM(revenue)` · Colour `category_name` |
| 3 | **Category YoY** | order_line_sales | Side-by-side bar | Rows `category_name` · Columns `SUM(net_revenue)` · Colour `YEAR(order_date)` |
| 4 | **Top 10 products** | product_performance | Horizontal bar | Rows `product_name` (Top-10 filter by `net_revenue`) · Colour `category_name` · Tooltip `repeat_buyer_pct` |
| 5 | **Product matrix** | product_performance | Scatter | Columns `units_sold` · Rows `repeat_buyer_pct` · Size `net_revenue` · Colour `category_name`. Shows which products bring customers back |
| 6 | **New vs repeat orders** | order_summary | Stacked bar | Columns `MONTH(order_month)` · Rows `CNT(order_id)` · Colour `new_vs_repeat` |
| 7 | **Customer segments** | customer_summary | Bar + label | Rows `customer_segment` · Columns `SUM(lifetime_value)` · Label % of total |
| 8 | **Cohort retention heat-map** | cohort_retention | Highlight table | Rows `cohort_month` · Columns `months_since_first` · Colour/Label `retention_pct` |
| 9 | **Revenue by region** | order_line_sales | Bar | Rows `region_name` · Columns `SUM(net_revenue)` |

## 4. Dashboards (1200 × 800)

**Dashboard 1: Sales performance**
```
┌──────────┬──────────┬──────────┬──────────┐
│ Revenue  │ Orders   │ AOV      │ Repeat % │   ← KPI tiles
├──────────┴──────────┴──────────┴──────────┤
│ Revenue trend by category (area)          │
├─────────────────────┬─────────────────────┤
│ Top 10 products     │ Category YoY        │
└─────────────────────┴─────────────────────┘
Filters: Year · Region · Category  (apply to all sheets using related sources)
```

**Dashboard 2: Customers & repeat purchasing**
```
┌─────────────────────┬─────────────────────┐
│ New vs repeat       │ Customer segments   │
├─────────────────────┼─────────────────────┤
│ Cohort retention    │ Product matrix      │
└─────────────────────┴─────────────────────┘
```

**Interactivity**
- *Dashboard action → Filter*: clicking a category in sheet 2 filters sheets 3–4.
- *Highlight action* on `customer_segment`.
- Parameter `Top N` (5/10/20) driving the Top products filter.

## 5. Publish

3. Take a screenshot → save as `tableau/dashboard_preview.png` (referenced in the README).
